# 📚 Книжный интернет-магазин "New Reader"

Проект представляет собой современное Fullstack-приложение интернет-магазина книг, закладок, письменных принадлежностей и аксессуаров, оформленное в уникальном минималистичном стиле «левитирующих» островных панелей (в духе «Читай-город»). 

Проект реализован на монолитной архитектуре с разделением прав пользователей на основе ролей (**RBAC**), защищенной сессионной авторизацией, складским учетом остатков и динамическим интерактивным фронтендом на **JavaScript** и шаблонизаторе **Jinja2**.

> **Jinja2** — это динамический шаблонизатор для HTML-страниц, который на бэкенде подставляет данные из Python-кода прямиком в разметку, избавляя от ручного дублирования кода.
> **Асинхронный фронтенд** — подход, при котором операции (добавление в корзину, поиск, лайки) выполняются через фоновые сетевые HTTP-запросы (**Fetch API**) в неблокирующем режиме. Пользователь продолжает свободно взаимодействовать с сайтом, пока данные обновляются мгновенно на лету без полной перезагрузки страницы.

## 🚀 Технологический стек

* **Backend:** Python 3.11+, FastAPI, Pydantic
* **Database & ORM:** SQLite, SQLAlchemy 2.0 (Declarative Mapping, ORM relationships)

## 🛠 Архитектура проекта и обоснование решений

### 1. Безопасность и многопользовательский доступ (RBAC)
Доступ к функциям жестко разграничен по ролям через поле `role` в модели пользователя. Авторизация построена на **HTTPOnly Cookie** сессиях, что защищает токены от кражи через XSS-скрипты:
* **Клиент (`client`)** — может регистрироваться, управлять корзиной, откладывать товары в избранное, покупать и просматривать детализированную историю своих трат.
* **Продавец / Издательство (`seller`)** — имеет доступ к изолированному дашборду для публикации товаров, отслеживания запасов на складе и начисления прибыли от продаж.
* **Администратор (`admin`)** — обладает сквозным доступом ко всей системе, логам транзакций и пользователям.

### 2. База данных и ORM связи (SQLAlchemy 2.0)
Вся работа с SQLite ведется через SQLAlchemy в современном стиле аннотаций типов (`Mapped[...]`), гарантируя автоматическую защиту от SQL-инъекций. Реализованы сложные реляционные связи:
* `User_obj` (`Users`) — учетные данные, роли, баланс, названия компаний.
* `Product_obj` (`Products`) — универсальная таблица товаров со складским остатком (`stock_quantity`) и типом (`product_type`).
* `Cart_obj` (`Cart`) — связующая таблица корзины покупателя.
* `Favorite_obj` (`Favorites`) — новая таблица связи для функции «Добавить в избранное».
* `Promo_obj` (`Promocodes`) — купоны со встроенным периодом валидности.
* `Buy_obj` (`Purchases`) — архив завершенных покупок. Отношения `relationship` позволяют админу и клиенту одной строчкой кода вытягивать названия книг и имена продавцов (`purchase.product.title`, `purchase.seller.username`).

### 3. Мягкое удаление (Архивация товаров)
По законам коммерческого учета, если продавец удаляет книгу, её нельзя физически стирать из базы данных, иначе разрушится лог истории покупок у клиентов. Реализован механизм **мягкого удаления**: флаг `is_active = False` скрывает товар с витрины для клиентов, но сохраняет его в логах для продавца и админа.

### 4. Асинхронный фронтенд (Fetch API)
Формы промокодов, добавления в корзину и лайков переведены на асинхронный `Fetch API`. JavaScript перехватывает событие отправки, отправляет фоновый запрос, получает компактный JSON и на лету перестраивает интерфейс (меняет счетчик цен, выводит плашки предупреждений, запускает анимацию скрытия карточки), полностью избавляя пользователя от перезагрузок страниц.

## 💡 Разбор ключевой бизнес-логики (Эндпоинты)

### 🌓 Динамическая смена темы (`static/js` / `index.css`)
Реализована через CSS-переменные (`--bg-page`, `--text-primary` и др.). При клике на кнопку `🌓` JavaScript мгновенно переключает класс `dark-mode` у тега `<body>` и сохраняет выбор в `localStorage` браузера, благодаря чему выбранный режим (светлый или тёмный) не сбрасывается при переходах по страницам и бережёт зрение пользователя ночью (особенно в читальном зале `read.html`).

### 🔍 Живой поиск товаров (`GET /api/search`)
JS-скрипт отслеживает ввод букв в поисковую строку шапки. Если введено больше двух символов, он отправляет запрос на эндпоинт `/api/search` и на лету рендерит выпадающий список карточек с результатами поиска по названию, автору или жанру прямо во время набора текста.

### 💳 Складской учет, Эквайринг и Оплата (`POST /purchase`)
Главный узел транзакций. При оформлении заказа бэкенд:
1. Вычисляет общую стоимость корзины и сверяет с балансом клиента (`current_user.balance`).
2. В цикле проверяет наличие каждого товара на складе (`product.stock_quantity`). Если товара нет — выбрасывается отмена.
3. При успехе: списывает баланс у покупателя, уменьшает складские остатки товаров, **автоматически начисляет деньги на баланс конкретного продавца** (издательства), создаёт записи в `Buy_obj`, очищает корзину и перенаправляет клиента на страницу с котиком. Если остаток товара падает до `0`, товар автоматически переходит в статус «Нет в наличии», блокируя кнопки покупки.

## 🎨 Особенности интерфейса (Стилизация)

* **Островной дизайн:** Наследование шаблонов Jinja2 (`{% extends "base.html" %}`) обеспечивает сквозной интерфейс. Навигационная панель оформлена в виде скругленной изолированной капсулы с `margin: 0 auto`, которая визуально «левитирует» над сайтом и прижата к внутренним стенкам с помощью Flexbox (`margin-left: auto`), адаптируясь под размеры экранов.
* **Пастельные кнопки:** Основные кнопки действия (`.buy-button`) переведены в современный нежно-голубой пастельный цвет с контрастным полужирным шрифтом и анимацией физического нажатия (`transform: scale(0.98)`).
* **Разделение окон:** Страница «Профиль» отвечает только за финансовую историю и личные данные, а «Мои книги» — за Избранное с интерактивным удалением карточек.

## 🛠 Инструкция по локальному запуску

**1. Установка зависимостей проекта:**
Убедитесь, что вы находитесь в директории проекта и у вас активировано виртуальное окружение, после чего выполните:
```bash
pip install -r requirements.txt
```

**2. Первоначальное наполнение базы данных (Важно):**
Перед первым стартом запустите сидирование базы данных. Скрипт создаст таблицы SQLite, сгенерирует ассортимент товаров разных категорий (книги, закладки, ручки), добавит ознакомительный текст, активный промокод `SALE100` и создаст 4 тестовых аккаунта с разным балансом:
```bash
python seed.py
```

**3. Запуск веб-сервера:**
Запустите сервер автоматического обновления приложения Uvicorn:
```bash
uvicorn main:app --reload
```
Откройте браузер по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)
